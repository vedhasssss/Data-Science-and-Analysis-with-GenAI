## How to Run

1. Install [Python 3](https://www.python.org/downloads/).
2. Run a file:
   ```bash
   python 01_basics.py
   ```
   Files saved as notebooks (`.ipynb`) open in Jupyter Notebook, VS Code or Google Colab.
