# 🐍 Python Learning Notes

A collection of Jupyter notebooks covering Python from the basics to object-oriented programming. Each notebook focuses on one topic, with examples and practice code written while learning.

> 🚧 This repo is a work in progress — more topics will be added as I continue learning.

## 📚 Topics Covered

| # | Notebook | Topic |
|---|----------|-------|
| 01 | `01_Basics.ipynb` | Python basics: variables, data types, input/output |
| 02 | `02_Operators.ipynb` | Arithmetic, comparison, logical operators |
| 03 | `03_if-else_operators.ipynb` | Conditional statements with if-else |
| 04 | `04_if-else-elif.ipynb` | Multi-branch conditions with elif |
| 05 | `05_loops.ipynb` | for and while loops |
| 06 | `06_loops_2.ipynb` | Nested loops, break, continue, loop patterns |
| 07 | `07_list_and_operations.ipynb` | Lists and common list operations |
| 08 | `08_dictionary_and_operations.ipynb` | Dictionaries and their methods |
| 09 | `09_String_operations.ipynb` | String methods and manipulation |
| 10 | `10_Set_Operations.ipynb` | Sets and set operations |
| 11 | `11_Tuple_Operations.ipynb` | Tuples and tuple operations |
| 12 | `12_Functions.ipynb` | Defining and using functions |
| 13 | `13_Lambda_and_datetime.ipynb` | Lambda functions and the datetime module |
| 14 | `14_Map.ipynb` | The `map()` function |
| 15 | `15_Filters.ipynb` | The `filter()` function |
| 16 | `16_Zip_Operations_&_Enumerate.ipynb` | `zip()` and `enumerate()` |
| 17 | `17_OOPs.ipynb` | Object-Oriented Programming: classes and objects |
| 18 | `18_Inheritance.ipynb` | Inheritance in OOP |

## 🛠️ Requirements

- Python 3.x
- Jupyter Notebook / JupyterLab (or VS Code with the Jupyter extension)

## ▶️ How to Use

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd <repo-folder>
   ```
2. Install Jupyter if you don't have it:
   ```bash
   pip install notebook
   ```
3. Launch it and open any notebook:
   ```bash
   jupyter notebook
   ```
