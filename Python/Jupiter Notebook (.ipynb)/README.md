I prefer to practice in .ipynb files.
So these are .ipynb files; if anyone has the same preference, they can use these too.
An .ipynb file is a Jupyter Notebook file. It allows you to write Python code in small sections called cells and see the output immediately.
In a .py file, we generally run the whole program. In an .ipynb file, we can run one cell at a time and check the result. 
.ipynb files can contain code, output, graphs, tables, and notes together. A .py file mainly contains Python code.
Simple Example: We can think of a .py file as a Python program, while an .ipynb file is like a Python notebook where we write code, run it, and see the results step by step.
